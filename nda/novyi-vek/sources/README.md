# Исходники кейса «Новый век»

Оригиналы, из которых собраны страница кейса (`../index.html`) и прототип сайта (`../site.html`).

- `brandbook-novyi-vek-inside.pdf` — брендбук: бриф, конкуренты, логотип, шрифт, палитра, дух, верстка, карты, банкомат, приложение
- `site-main-structure.pdf` — макет главной страницы сайта
- `site-ved.pdf`, `site-ved-menu-hover.pdf` — блок услуг и он же с открытым меню при наведении
- `site-credit.png`, `site-news.png` — калькулятор кредита и новости (кадры из PDF, сами PDF удалены)
- `storyboard-1.png` … `storyboard-3.png` — раскадровка первого экрана: карта → ребро → монета (кадры из PDF)
- `card-silver-original.webp`, `card-red-original.webp` — карты, присланные отдельно
